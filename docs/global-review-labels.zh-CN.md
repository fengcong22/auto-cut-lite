# 全片意见只标注

Auto-Cut Lite 1.6.13 在指定修改意见区域或素材要求清单中，同时读取普通段落、列表、
复选框。标题、文件名、附件大小和明确标为示例的文字不进入意见清单；不会扫描任意
课程正文并将其作为指令。原文逐字保留，勾选仅记录来源状态，不代表已经执行。

范围判断与执行能力分开：明确的“全片／全程／整段素材”要求，或维护的变声音色、
隐藏工具栏、粗剪清单模式，可以归为全片标注。局部时间优先；没有时间本身不是
全片依据。“这里隐藏工具栏”“删除这句话”等仍是局部意见。

局部意见优先使用可靠的 ASR 定位或意见原有时间。仍缺时间时，只标注、不执行：
标签紧接前一条局部标签显示（前一条起点加两秒），连续缺时间则依次排列；
第一条局部意见没有时间则放在 0:00。已有时间的意见不移动。标签排到片尾时截短，
必要时使用独立轨道，绝不延长素材或改变音视频位置。
内部 `label_placement` 记录前一条意见 ID、展示位置、截短情况，
`timing_source=document_order_fallback` 明确是展示回退。它不能作为 ASR 搜索时间、
删词边界或视觉修改的执行依据；音频类意见仍先尝试 ASR。

清单紧随录屏附件时，保留附件绑定；多素材必须唯一匹配。独立意见区域只有一个
视频时可以绑定该视频，多视频且范围不明时保留未确定状态并阻止猜测标注位置。
只有明确“整个工程／全部视频”才使用工程范围。不支持的词义或结构仍可能需要补充
范围说明，当前规则不声称能理解任意自然语言。

明确全片项统一为 `global_review`，始终 `execution_required=false`，内部状态
为 `label_only_global_review`。每项一条原文标签，进入独立 `Review Marker Global N`
轨，展示在所属素材起点，最长两秒并在该素材结尾截断。素材起点可以是 0 秒，但它
是有来源依据的全片展示位置，与局部意见按文档顺序回退的规则分别记录。

内部 `review_scope` 保存作用范围、目标素材序号、范围依据和 `placement_basis=scope_start`。
根草稿和活动时间线核验原文、数量、展示起点、标签轨及回执；报告的
`global_review_labels` 明确 `executed=false`。标签不修改音视频、剪辑点或项目时长。
全文原文中不添加“全片”“未执行”等前缀。

验证覆盖混合文档、前后正文隔离、附件关联不串项、三类截图意见、局部缺时间顺序标注、
指定局部时间保留、多素材绑定、整个工程范围、短素材末尾、保存后原文与回执、
全片意见与精确删词共存，以及不触发全片 ASR／编辑。测试与发布不重跑用户业务任务。
