## 一句话定义

这类视频是典型的“教育产品电商口播 + 实物屏拍演示 + 促销花字连击”短视频。

它不是电影感广告，也不是生活流 vlog。核心任务只有三个：
- 先用口播快速打痛点
- 再用产品界面证明“东西真的很多”
- 最后用价格、赠品、跨度和承诺完成转化

## 结构模板

### 版本 A：最常见结构

1. `0s-6s` 痛点开场  
   主播半身正对镜头，直接抛问题。花字先打“问题/反差”。

2. `6s-10s` 方案亮相  
   把“小初4年卡”“4298元”“4年全解决”这种核心卖点抛出来。

3. `10s-30s` 产品证明段  
   切到平板实拍或录屏，连续展示课程页、年级页、题库页、私教页、赠品页。

4. `30s-40s` 价格拆解段  
   回到主播，或者继续产品页叠价格花字，突出“4年”“每天不到3元”“一次覆盖多学段”。

5. `40s-结尾` 收口 CTA  
   主播收尾，配角色贴纸、点赞手势或结论型花字，例如“值”“就选它”“别踩坑”。

### 版本 B：变体开场

样片 4、5 还用了两个变体：
- 先上夸张情境或反差画面，再回到产品
- 先上课程海报，再切真实产品页

这两个变体都服务同一件事：前 3 秒抓停留，后面还是回到“口播 + 产品证明 + 价格转化”。

## 画面风格

### 1. 主播镜头

共同点非常稳定：
- 单人正中构图
- 半身或中近景
- 镜头固定，几乎不做推拉摇移
- 主播穿白衬衫 + 领带，偏“老师/学长/班主任”人设
- 室内背景干净，桌面在前景形成稳定横线

可接受的背景：
- 浅米白墙面 + 木色桌面
- 绿色墙面 + 装饰画
- 浅色窗帘背景

结论：后续同风格制作时，A-roll 不需要花哨机位，关键是“正、稳、像在跟家长直接说话”。

### 2. 产品展示镜头

产品证明几乎都靠这些画面：
- 平板正面实拍，黑色支架固定
- 蓝底课程界面
- 课程分类、年级切换、题库、私教、赠品页轮流展示
- 角色立绘、学科标签、按钮区域始终可见

这类画面不是“氛围素材”，而是“转化证据”。

### 3. 字幕

底部字幕统一是：
- 白字
- 细黑描边
- 居中贴底
- 作为口播同步字幕，不抢主花字

## 颜色体系

样片主色非常稳定，可以直接抽成 5 个角色颜色：

| 角色 | 颜色建议 | 用法 |
| --- | --- | --- |
| 背景白 | `#EDF0EB` / `#F0F2EE` / `#FCFDF9` | 墙面、字幕留白、海报背景 |
| 产品蓝 | `#3380E7` / `#3684EB` / `#6290CC` | 平板课程页主底色 |
| 强调黄 | `#F6D44A` 近似 | 价格、课程利益点、赠品、核心结论 |
| 促销红 | `#F44336` 近似 | 痛点、降价、警示、CTA |
| 阴影深灰 | `#2B252F` / `#34303A` / `#383249` | 花字描边、阴影、压重 |

辅助色：
- 金棕/米金：`#C6AB87` / `#D2AA6A` / `#E6D5B5`
- 浅灰绿：`#C2CEBD` / `#C4CCC3`

视觉感受：
- 主体干净明亮
- 产品页高饱和蓝
- 花字靠黄、红、白形成强对比
- 阴影较重，故意做出“电商强调感”

## 花字模板

## 花字尺寸口径

这类竖屏半身口播的花字必须匹配画面大小，不能做成胸前小贴片。

- 短花字要按主标题处理，单行通常占画面宽度约 `28%` 到 `42%`
- 两行花字块通常占画面高度约 `10%` 到 `18%`
- 痛点、产品名、AI 私教、题库、价格这些关键卖点都应明显大于普通字幕
- 如果截图里花字看起来只在胸口占一小块，接近“字幕标签”，就判定为太小
- 优先通过增大字号和 `scale_x` / `scale_y` 修正，不要只移动位置
- 模板壳子如果限制了实际大小，就切回 plain editable flower text

### 花字 1：痛点/问题型

适用文案：
- “小学基础不牢”
- “记不住 审题漏 难题懵”
- “小升初衔接别乱报班”

视觉特征：
- 红字或红底白字
- 黑色重阴影
- 可做 2-4 行堆叠
- 放在主播胸口到腰部中间区域

### 花字 2：方案/产品型

适用文案：
- “小初4年卡全解决”
- “小学1-6年级语数英同步课”
- “初中7科同步课”

视觉特征：
- 黄字
- 紫黑或黑色粗描边
- 带轻微斜切或弹入感
- 旁边常加短促光线、星点、笔刷下划线

### 花字 3：价格锤型

适用文案：
- “仅4298元”
- “直降1万+”
- “4年每天不到3元”

视觉特征：
- 红白高反差
- 常带闪电、箭头、爆点
- 字号比普通卖点更大
- 节奏点更重，通常配一次明显音效

### 花字 4：赠品/权益型

适用文案：
- “AI私教”
- “3个月助教”
- “双试卷库”
- “小升初衔接课”

视觉特征：
- 黄字为主
- 黑描边
- 一屏最多 2-4 条，不要挤太满
- 常叠在产品页下半部

### 花字 5：结论/收口型

适用文案：
- “值”
- “小升初不踩坑就选它”
- “痛点全解决”

视觉特征：
- 更短、更大
- 可以单字或 1 行短句
- 常在结尾或最后一轮产品证明时出现

## 贴纸和装饰元素

样片里反复出现的不是大面积贴纸，而是“小道具式强调”：

### 高频元素

- 卡通秃头小人/小孩反应贴纸
- 手指点击贴纸
- 红框高亮
- 手绘箭头
- 闪电/爆点
- 下划线笔刷
- 放射短线
- 点赞手势小图标
- 感叹号

### 用法规律

- 贴纸不长期挂屏，通常只停 1-3 秒
- 主要出现在痛点句、价格句、按钮句、结尾句
- 位置多在右下、左下、按钮附近、标题旁边
- 功能是“加情绪”和“指视线”，不是装饰满屏

## 剪辑节奏

从抽帧和镜头变化看，整体节奏是：
- 大多数镜头维持 `1.5s-3s`
- 转场以硬切为主
- 不依赖复杂转场
- 花字进场比镜头变化更重要

结论：真正驱动节奏的是“文案节点 + 花字节点 + 产品页切页节点”。

## 音频模板

无法仅凭导出 mp4 100% 反推原始素材包 ID，但可以确定音频设计逻辑。

### 1. 口播

- 男声口播是绝对主角
- 字幕基本逐句同步
- 语速偏快，句子短，结论先行

### 2. 背景音乐

音乐气质不是抒情，而是：
- 轻快
- 促销感
- 带律动
- 不压人声

推荐后续优先搜索这些方向：
- `企业形象进取创新 Upbeat Corporate Motivational`
- `轻快 童趣 快乐 综艺`
- `Tropical House`
- `时尚放克 Funk`
- `放克律动节拍 Happy Upbeat Summer Funk`

### 3. 音效

后续建议按节点补这些音效类型：
- 花字弹入：`俏皮弹跳吉他2` / `俏皮弹跳弦乐12`
- 快速强调：`“wei 咻！”`
- 结论敲点：`卡通滑稽咚声1` / `卡通滑稽鼓点2`
- UI 提示：`科技提示音效`
- 综艺感补强：`综艺俏皮木琴1`
- 登场/权益亮相：`闪亮登场音效A`

注意：这些是基于样片风格匹配出的可复用候选，不是对原始工程素材 ID 的反向确认。

## 后续制作时的镜头配方

当你给我新的实拍素材时，我会优先按这套配方出片：

1. 开头先从你的口播里截 2-3 个最狠的痛点句
2. 在第一个完整结论句上打第一组大花字
3. 在 8 秒内把核心产品名和价格抛出来
4. 中段切入产品页或录屏，连续证明“覆盖学段/学科/题库/私教/赠品”
5. 每个证明点只说一件事，花字只打一层，不堆解释
6. 结尾回到人，或者继续产品页叠价格拆解和 CTA
