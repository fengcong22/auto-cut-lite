# Local Image Overlay

Use only the supplied local image or an explicitly named public asset. Save it as an editable material and place it at the resolved `timeline_time_range` start. Keep neighboring tracks and the original source visible. In lite mode the overlay is validated for material presence and start alignment; do not infer a subject-specific profile or silently calibrate from a private library.
