# Auto-Cut Lite

这是 Auto-Cut 的通用精简版 Codex 包，包含 17 个工作区技能。精准删词仍使用字/词级 ASR
确定真实切点，并只写入非破坏性的可编辑切点追踪；源媒体和项目总时长保持不变，标签从真实
切点开始，而不是直接采用修改意见里的粗略时间。动画、画面时序和原有
小手遮挡清理仅保留原文标签；用户提供的小手或局部图片按剪映默认几何贴入，不自动位移、缩放、
制作关键帧或校准落点。

剪映中每条可见标签只逐字符显示该条修改意见的 `source_text` 原文，不会附加状态、编号、警告或
处理说明。新问题暂时无法安全处理但时间可靠时，程序只在内部元数据/回执/报告中记录
`execution_status=label_only_unresolved`，草稿里仍只贴一条原文标签，并继续处理其他项目；时间不可靠，
或音频问题缺少权威 ASR 时，会在写草稿前停止，不会猜到修改意见时间或 `0:00`。

Lite 的精准删词只切不删，不会压缩时间轴，成片时长始终等于源视频时长。“停顿 +1 秒”、延长、缩短或其他停顿调整
都不会实际改动时间轴：程序先用字/词级 ASR 找到真实位置，再只贴一条修改意见 `source_text` 原文
标签；不会创建静帧、hold、音频空隙或 `pause_adjustments`，也不会改变总时长或移动后面的任何视频、
音频、素材和标签。A2 每个逻辑删除窗口保留一个独立、可听片段；不同修改意见的相邻窗口不合并，
真实重叠会在写草稿前停止并要求消歧。`copy` 仅用于识别历史草稿，新任务只执行 `split_gap`。

自然语言审阅文档任务默认由 `review-document-run` 一键执行：源 ASR 和完整候选反向
ASR 按严格内容身份去重，中断后只恢复仍有效的阶段，缺失或损坏产物会重跑对应阶段，
不会现场生成临时 Python 脚本。缓存命中不会跳过切口、`must_keep`、反向 ASR 或最终剪映草稿
验收。

本版采用“合并工作区 + 独立运行时”模式：

- 新手只需“全部解压”，再双击 `一键安装或升级-Auto-Cut-Lite.cmd`；默认使用国内镜像。
- 首次部署会弹窗选择路径；选定的 `Auto-cut-lite` 将保存完整包文件并作为 Codex 工作区。
- 可以直接选择解压出的 `Auto-cut-lite`，也可以选择另一个 Codex 工作区位置；部署器会把完整包同步过去。
- 工作区同时保存包文件、`AGENTS.md` 和 `.codex\skills`。
- 真正执行任务的插件和 Python 环境仍安装在 `%LOCALAPPDATA%\Auto-Cut\auto-cut-lite`。
- 每次非模拟任务都会校验已部署运行时；若文件被现场修改、缺失或与包清单不一致，必须使用已验证
  的安装包重新部署，不能继续热改运行时或切换到其他源码目录执行。
- 升级时把新 ZIP 解压到临时位置并运行新部署器；部署器按旧回执更新原工作区。
- 插件清单不注册 `skills`，包内也没有顶层 `skills`，因此技能应显示为仓库范围
  `Auto-cut-lite`，而不是重复的 `Personal`。

请从 [Auto-Cut-Lite新手部署说明.md](Auto-Cut-Lite新手部署说明.md) 开始。正常安装不需要打开 PowerShell、
进入目录或替换路径；部署完成后按 [Auto-Cut-Lite部署成功后操作说明.md](Auto-Cut-Lite部署成功后操作说明.md) 继续配置本机环境。
